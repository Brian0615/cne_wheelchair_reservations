# CNE Wheelchair Reservations Manual

Last updated: August 14, 2025 8:09:00 PM

## 1 Reservations

### 1.1 Creating a New Reservation

To create a new reservation:
Navigate to the New Reservation page (1)
Fill in the form with the reservation information (2)
Click Submit (3)
To view the number of remaining reservations available for each day, expand the dropdown labelled “View Reservation
Availability” (4)

### Updating an Existing Reservation

To modify an existing reservation:
Navigate to the Manage Reservation page (1)
Select the date of the reservation (2)
Select the reservation to be modified (3)
After selecting the desired reservation, the following may be performed:
Confirm a reservation (4)
Note: This option is only available for scooters
Cancel a reservation (5)
Update information about the reservation (6)
Note: The reservation date and type (scooter/wheelchair) may not be modified. To do, the reservation must be cancelled
and a new reservation will need to be created.
Any reservation that has been cancelled, picked up, or completed (i.e. returned) may not be modified.

### Reservation Availability

To view the number of available or taken reservations, navigate to the Reservation Availability page (1).
On this page, users with the admin role may modify the maximum reservations allowed per day (2). Note that:
The limit for wheelchair and scooter reservations can be set independently
The limit is applied for all days – i.e. different limits cannot be set for different days
If the reservation limit is reached, any new reservations will automatically be put on the waitlist. However, if the
reservation limit is reduced, any prior reservations (even if above the limit) will not be modified

### Reservation Status

Reservations are assigned one of the following statuses:
Waitlisted
Reserved
Pending Confirmation
Confirmed
Picked Up
Completed
Cancelled

#### Scooters

Scooter reservations are automatically assigned the Pending Confirmation status when first created
If there are no more available reservations, the reservation is assigned the Waitlisted status instead
After calling to confirm a scooter reservation, the reservation can be marked as Confirmed using the Manage Reservations
page
When a rental for the reservation is created, the reservation status will automatically be updated to Picked Up
When the rental is completed, the reservation status will automatically be updated to Completed

Wheelchair reservations are automatically assigned the Reserved status when first created
If there are no more available reservations, the reservation is assigned the Waitlisted status instead
When a rental for the reservation is created, the reservation status will automatically be updated to Picked Up

## Rentals

### 2.1 Creating a New Rental

To create a new rental:
Navigate to the New Rental page (1)
Complete the following fields: (2)
Rental Date – this field will default to the current date
Pickup Time – you may either enter a time or select a time from the dropdown
Pickup Location – select BLC or PG from the dropdown
Rental Type – select Scooter or Wheelchair from the dropdown
Once the first four fields (2) are completed, you may fill in the remainder of the form:
Select the reservation: (3)
For guests with a reservation, choose their reservation from the dropdown.
For guests without a reservation, select the Walk In – No Reservation option. This is the last option in the dropdown.
Select the scooter/wheelchair number (4)
Fill in the renter information (5), and check the box (6) once you’ve verified ID
Fill in payment information (7)
Fill in your name under Staff Name, and list any items left behind by the renter (8)
Once everything is complete, click Submit (9) to start the rental.
After clicking Submit, you will see one of the following:
Success: If all the information has been verified successfully, you will see a green success dialog (10).
Click Download (11) to download the rental form so it can be printed.
Afterwards, click Close (12) to return to the main page.
Error: If there is missing or invalid information, you will see an error (example: (13)). Please correct any missing
information and try to resubmit the form

#### 2.1.1 Credit Card Deposits

Please use the paper credit card deposit slips to record credit card information. Do NOT include any credit card
information in the reservation system.

#### 2.1.2 Troubleshooting

The remainder of the form will not appear unless the first four fields (2) are filled
You may need to scroll down to see all the fields
If you accidentally close the Success pop-up without downloading the rental form, see the instructions in Section 2.4
for a way to retrieve the rental form.

### Modifying an Existing Rental

If a wheelchair or scooter needs to be swapped out during a rental, do the following:
Navigate to the Manage Reservations page (1)
Select the date (2) and the rental (3)
The date will default to the current date
To select a rental, you may choose an option from the dropdown, or search by typing in one of the following:
The current wheelchair/scooter ID
The renter’s name
The rental ID found on the rental form
After selecting the rental, the option to update the wheelchair or scooter will appear. You will then need to:
Select the current location from the dropdown (4)
This does not need be the same location as the pickup location
Select the new wheelchair or scooter ID from the dropdown (5)
Enter your name under Staff Name (6)
Click Update Wheelchair or Update Scooter (7)
This button will only be clickable if all the required fields are completed
Notes:
The option to update a wheelchair / scooter will not appear if a rental is not selected
The option to update a wheelchair / scooter will be disabled if the rental is already completed.

### Completing a Rental

When a wheelchair or scooter rental is brought back, please complete the following:
Navigate to the Complete Rental page (1)
Select the date (2) and the rental (3)
The date will default to the current date
To select a rental, you may choose an option from the dropdown, or search by typing in one of the following:
The current wheelchair/scooter ID
The renter’s name
The rental ID found on the rental form
After selecting the rental, the form to complete the rental will appear. You will then need to:
Select the Return Date (4) – the date will default to the current date
Select or type in the Return Time (5)
Select the Return Location (6)
Enter your name under Staff Name (7)
Confirm by checking the boxes (8) that the deposit, and any items left behind during the rental have been returned
Click Complete Rental (9)
This button will only be clickable if all the required fields are completed

### Retrieving a Rental Form

To retrieve a rental form, complete the following:
Navigate to the Manage Reservations page (1)
Select the date (2) and the rental (3)
The date will default to the current date
To select a rental, you may choose an option from the dropdown, or search by typing in one of the following:
The current wheelchair/scooter ID
The renter’s name
The rental ID found on the rental form
After selecting the rental, the option to download the rental form will appear. You can then click Download (4) to
download the rental form.
